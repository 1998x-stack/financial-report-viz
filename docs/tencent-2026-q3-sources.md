## 容易混淆的项目

1. **651亿元 vs 814.33亿元**：前者为2026 Q3现金资本开支付款（管理层以0.1十亿元取整），后者为应计资本开支金额，不能相加；管理层在电话会议提示应计资本开支与预付款的双计问题。
2. **-691亿元自由现金流**：现金经营约26亿元 - 资本开支付款约651亿元 - 媒体内容约46亿元 - 租赁约20亿元 = 约-691亿元。均为披露取整值。**不是**九个月现金流量表的经营现金流。
3. **+0.8% IFRS归母 vs -6% Non-IFRS归母**：不是同一个利润指标，投资相关收益等会改变IFRS归母。
4. **AI业务经营贡献**：公司披露不含新AI产品贡献的Non-IFRS经营利润约833亿元，与实际680.73亿元差约152.27亿元。此差额不是AI整体研发开支、不是当季计算资源付款，也不能据此推断AI未来利润。
5. **云增长35%**：只披露百分比，未单独披露云收入绝对值与净利率，因此不能推导云增长的精确集团收入贡献。
